# Piaoklxt-MusicWallpaper

v1.4.0 增加自动跨虚拟桌面、资源管理器文件夹大小、原生歌词配色与媒体命令，并完善应用配色和拖动性能。

[English](README.en.md)

[![构建便携版](https://github.com/piaoklxt-boop/Piaoklxt-MusicWallpaper/actions/workflows/build.yml/badge.svg)](https://github.com/piaoklxt-boop/Piaoklxt-MusicWallpaper/actions/workflows/build.yml)

把 QQ 音乐当前窗口变成可交互的 Windows 动态桌面。它保留 QQ 音乐播放页的动画效果，可直接在桌面点击原有播放控件，还能让 Windows 强调色随歌词页原生高亮色变化。

## 主要优势

- QQ 音乐画面实时铺在桌面图标后方，无需让 QQ 音乐窗口一直停在前台。
- 桌面播放、进度条单击与拖动、歌词时间跳转、音量、播放顺序和歌词滚动均可直接操作。
- 点击评论按钮会直接打开 QQ 音乐独立的原生评论窗口；点击桌面空白处即可收起，主界面继续留在桌面后方。
- Windows 强调色、任务栏、受支持应用的窗口顶部及文件资源管理器可随播放页自动配色。
- 提供完整的 x64 便携包：解压即用，并可自动寻找或启动 QQ 音乐。
- 关闭桌面渲染或退出程序时自动恢复原系统配色。

## v1.4.0 版本更新说明

- 自动固定 QQ 音乐源窗口到所有虚拟桌面，重开播放器后重新检查，继续共用一个渲染器。
- 文件夹大小直接显示在资源管理器“大小”列，后台计算、缓存并自动更新；可在控制面板独立关闭。首次大目录可能需要等待，Explorer 重启后需重新计算。
- 单色与渐变单色只读歌词页原生高亮色属性，不再使用截图或像素取色；播放／暂停、上一首、下一首优先使用媒体会话接口。
- 提供原色／浅色／深色、渐变单色及更明显的炫彩；普通应用与 Word／Excel／PowerPoint 的渲染范围分别控制。
- 改善拖动窗口时的残影、资源管理器亚克力拖动卡顿和主题通知等待；外观设置原地更新，不重启整套组件。

已知问题：曾在点击歌词翻译“译”后发生 QQMusic.dll 崩溃，根因尚未确认。不同 QQ 音乐版本、Office 版本和 Windows 构建仍需实机验证；原生属性与接口不可用时按各功能的兼容策略处理。

## 下载与使用

1. 从 [Releases](https://github.com/piaoklxt-boop/Piaoklxt-MusicWallpaper/releases) 下载 `Piaoklxt-MusicWallpaper-v1.4.0-win-x64.zip`。
2. 将压缩包完整解压到任意可写目录。
3. 双击 `Piaoklxt-MusicWallpaper.exe`。

不需要安装编译器、SDK、运行环境，也不需要手动配路径。程序不附带 QQ 音乐，请先安装官方 Windows 客户端。程序启动时会从运行中的进程、卸载信息和常见目录自动查找并打开 QQ 音乐；自动检测失败时，也可在托盘菜单中重新检测或手动选择 `QQMusic.exe`。

## 操作

- `Ctrl+Alt+U`：打开或关闭桌面壁纸。
- 托盘菜单首项：暂停壁纸并恢复 QQ 音乐，或重新启用壁纸；两种状态共用一个入口。
- 双击托盘图标或选择“控制面板…”：设置主题同步，以及资源管理器透明度、底色亮度、文件区域亚克力开关、侧边栏和顶部样式；文件区域开关作用于文件列表及其空白区域，独立于侧栏和顶部。修改后点击“应用”，也可恢复默认选项后再应用。
- “Microsoft Office”页可分别启用 Word、Excel、PowerPoint，并切换界面、内容区域和颜色强度。只改变屏幕显示，关闭主题或暂停壁纸后恢复；不修改文档或打印颜色。单色主题跟随播放／暂停键，炫彩主题在同一区域内混合移动多种颜色。区域识别与验证边界见 [外观渲染说明](docs/appearance-rendering.md)。
- 托盘菜单同时提供播放器路径、开机自启、检查更新、诊断导出、作者信息和退出。
- 桌面的音量和播放顺序使用稳定的壁纸弹窗，修改结果会在后台应用到 QQ 音乐。
- 点击或拖动桌面进度条可跳转播放位置，拖动时预览即时跟手、松手后跳转；点击歌词旁的时间标签也可直接跳转。播放、上一首和下一首优先使用 QQ 音乐公开的控件边界，不再依赖大范围坐标。
- 点击评论会在后台按 QQ 音乐公开的控件边界打开独立评论窗口，以便完整查看和操作评论；QQ 音乐主界面不会被搬到桌面前方。
- 首次运行默认开启开机自启，可在托盘菜单关闭。

设置和日志存放在 `%LOCALAPPDATA%\Piaoklxt-MusicWallpaper`，不会污染解压目录，也能从只读目录运行。首次启动会自动导入旧版 `QQMusicWallpaper` 目录中的设置。

## 兼容性

- Windows 11 x64：正式支持。
- Windows 10 1903 及以上：实验性支持。
- 需要另外安装 Windows 版 QQ 音乐。

壁纸镜像的是 QQ 音乐主窗口。拖动播放器底部进度条时，Windows 光标会正常移动，松手才向 QQ 音乐提交一次跳转；歌词旁公开的时间标签也可跳转播放时间，歌词滚动可正常使用。QQ 音乐的评论面板属于独立原生窗口，因此点击评论时仅打开并显示该窗口，点击桌面空白处可将其收起，主界面继续留在桌面后方。

Windows 11 便携包内置精简的文件资源管理器着色运行时，可让资源管理器顶部跟随当前强调色，不需要另外安装 Windhawk。检测到已有 Windhawk 正在运行时，内置运行时会保持关闭，避免冲突。

进入桌面渲染时，程序会保存当前 Windows 配色；关闭桌面渲染或退出程序时会恢复原配色，再次进入时重新保存并开始新的配色会话。

## 隐私与更新

程序不采集遥测数据。自动检查更新只会通过 HTTPS 访问本仓库的 GitHub Releases API；也可从托盘菜单手动检查。

## 从源码构建

需要 Visual Studio 2022 C++ 桌面生成工具、可构建 `net40` 的 .NET SDK 和 NuGet CLI。运行 `scripts\build-release.ps1`，便携目录和 ZIP 会生成到 `artifacts`。
