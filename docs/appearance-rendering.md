# Office 与流动主题渲染

控制面板的 Microsoft Office 页分别控制 Word、Excel、PowerPoint。界面区域、内容区域和颜色强度独立保存。内容包含 Word 编辑区域、Excel 网格和 PowerPoint 幻灯片；显示效果不写入文档格式，打印／导出的原始颜色不变。

单色模式直接读取 QQ 音乐歌词页的 `SV_HighlightColor` 命名属性。主题同步不调用截图、像素或控件坐标采样；隐藏、移窗和背景动画不会阻断属性读取。读取失败时保留已确认的属性色，旧版画面取色缓存不参与恢复。私有属性布局按模块哈希验证，详见 [原生歌词色读取](native-lyrics-color.md)。自动明暗通过 `SV_Major` 前景文字色判断歌词页明暗，与高亮色独立。

暖色、冷色、全色炫彩同时保留多个颜色区域，以不同运动轨迹持续混合。动画在主题工作线程的显示层刷新，系统强调色使用稳定代表色，避免每帧广播系统设置。显示层为不激活、鼠标穿透的分层窗口，跟随原窗口层级、位置与最小化状态；关闭功能、暂停壁纸或退出后销毁。

炫彩使用高饱和颜色、较大的运动幅度和独立深浅变化，减少混色发灰。“渐变单色”沿用播放键基色，在同一色相内形成 30%–100% 亮度的流动渐变；黑白按键对应灰阶渐变。控制面板按主题、资源管理器、任务栏、Office、其他应用排列，底边延伸及采样深度并入任务栏页。动态预览展示配色，各区域的实际显示强度仍由对应设置决定。

## 区域识别

- 配色覆盖资源管理器、任务栏、Office 及其他普通应用主窗口。普通应用默认开启，独立调整强度；仅识别可见、非最小化的普通顶层窗口，排除工具提示、菜单、桌面、QQ 音乐源窗口及控制器自身。无边框特殊窗口、提升权限／受保护窗口和专用弹出窗口可能不在覆盖范围。
- 任务栏颜色独立于亚克力开关；色层与亚克力共用任务栏透明度，任一开启时滑块可用。关闭色层不改变亚克力本来的 Windows 底色。Office 的专用开关不会被普通应用回退路径绕过。
- 原色／浅色／深色只作用于显示色层，不切换 Windows 黑白主题，也不把变浅／变深的颜色写回系统强调色。自动明暗和默认深色独立控制应用主题；自动明暗采样音乐画面而非炫彩代表色。开启系统强调色不再强制任务栏深色，具体强调色显示区域由 Windows 决定。
- Word、Excel 使用可见编辑控件的实时边界；未暴露这些控件的版本尝试 UI Automation。
- PowerPoint 优先通过已运行实例的只读对象模型取得活动普通／幻灯片视图的画布坐标，核对文档窗口身份并拒绝重名歧义。无法确认时再尝试 UI Automation。不会启动、激活或编辑 PowerPoint。
- 单独开启界面或内容时，未知区域不着色；同时开启两者时渲染整个编辑窗口。PowerPoint 特殊视图、放大至画布超出窗口、后台非活动文档或未注册运行对象的情况可能触发前一种保守退让。
- Word／Excel 的编辑区域可能包括纸张周围空白、网格表头等原生控件范围。Office 使用半透明颜色显示层，不宣称修改其原生材质或增加原生亚克力。
- 外观坐标使用局部线程 DPI 上下文，避免改变既有 QQ 音乐输入坐标体系。

## 验证

主题通知通过单个后台任务合并发送，每个接收窗口的每条消息最多等待 100 ms，不在设置锁或动画线程等待。只有注册表值实际变化才通知，避免只改显示强度等设置也广播主题刷新。此设计避免 [广播超时按窗口累加](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-sendmessagetimeoutw) 阻塞设置线程；无法保证第三方接收者自身永不挂起。

播放画面取色使用单个后台请求，慢捕获不堆积线程，短期缓存过期后保留已有有效配色；暂停／新会话丢弃旧会话结果。操作日志分别记录原生运行时、渲染器消息、主题队列及主题保存阶段，方便定位未完成的设置应用。冲突回归覆盖慢通知、原生超时、合并请求、慢捕获、18 种配色／深浅／自动明暗组合、重复注册表写入抑制和独立任务栏透明度。这些测试验证阻塞机制与防护，不宣称证明某次没有堆栈的历史卡死根因。

窗口移动通过 [Windows WinEvent](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-setwineventhook) 接收开始、结束和位置变化。交互拖动／缩放期间隐藏独立色层，结束后的动画帧按实时几何恢复；程序化移动时先撤下过期色框。回调不扫描无障碍树、不绘图，暂停和退出先解除事件订阅再清理显示层。原生亚克力继续由目标窗口自身呈现。

motion 回归通过自有测试窗口发出的原生移动事件覆盖拖动中隐藏、尺寸变化、结束恢复、无关窗口隔离及暂停后迟到事件。broad 回归覆盖外部进程普通窗口识别与关闭开关，所有显示层的明暗和动画切回单色，以及设置兼容。`--installed-theme-fixture <controller-pid>` 用自有空白窗口验证已安装控制器的实际覆盖及移动恢复，不拖动或截图用户工作窗口；这不等于所有应用和系统缩放下的真实鼠标拖动验收。

`ControllerRegression.Tests` 的 appearance 用例覆盖控制面板提交与保存、区域遮罩、真实测试窗口的归属／非激活样式／移动／最小化、暂停清理、多色空间差异与时间变化、原生命名颜色属性读取、缺失／错误属性拒绝、损坏或并发变化的数据树拒绝及禁止画面取色。其他四套回归和播放模式脚本继续按 AGENTS.md 执行。

vivid 用例经真实显示层绘制后计入默认 Office 透明度，检测两秒画面变化量，避免只检查原始颜色图就误判效果明显。另覆盖渐变基色传递、设置兼容、页面分组，以及最小窗口和 9／12／13.5 点字体下的控件交叠。量化变化与合成画面用于回归，不代替用户对实际效果的判断。

可选 `--appearance-probe` 只读检查当前应用几何和渲染窗口；输出不含文档标题或正文。`--appearance-fixture <HWND>` 仅用于专门创建的空白 Office 测试文档，可检查实际区域开关并保存测试画面。此模式不会选择或编辑文档；不得把用户日常文档作为截图夹具。被遮挡的画面会跳过屏幕截图，单独标记原窗口截图，不能据此宣称显示层已通过视觉验证。

本机临时文档验证已覆盖 Word、Excel、PowerPoint 普通视图的区域切换和清理。Word 已观察到实际流动显示与内容区独立着色；其他被遮挡的实窗截图不计入视觉验收。合成颜色图和自动回归不能代替不同 Office 版本、缩放、多显示器、PowerPoint 特殊视图及实时 QQ 音乐采样的最终验收。
